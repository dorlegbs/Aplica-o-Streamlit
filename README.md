# Comunicação Digital Global

O App "Comunicação Digital Global" consiste na apresentação de um dashboard (inteface visual interativa) que mostra diferentes aspectos da comunicação em âmbito global. 

Inicialmente, o usuário seleciona um país de interesse e o sistema informa sobre a população, o uso da Internet e o uso de redes sociais, além do idioma do país. A partir disso, são apresentados dois gráficos sobre a evolução do acesso à internet e sobre crescimento anual desse acesso. 

O usuário tem acesso, também, à uma estimativa do uso das redes sociais de determinado país considerando a população d ecada país.

O programa permite a comparação de dois diferentes países e fornece um resumo final comparativo.

A interface interativa permite que o usuário selecione o que deseja exibir.

O obejtivo é analisar a evolução do acesso à internet e visualizar tendências a partir da comparações de métricas.
